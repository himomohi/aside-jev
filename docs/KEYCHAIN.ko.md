# macOS API 키 저장

macOS의 간편 `setup`은 현재 사용자의 기본 **파일 기반 macOS 키체인**에 API 키를 저장합니다. 새 `api.env`를 만들지 않습니다. Windows는 기존 환경 파일 방식을 유지하며, Python 의존성을 추가하지 않습니다.

## 설치·이전·교체·삭제

```bash
uv run aside-jev setup
uv run aside-jev keychain status
uv run aside-jev keychain migrate
uv run aside-jev keychain set
uv run aside-jev keychain delete
```

의존성이 설치된 소스 폴더에서 실행합니다. `set`은 터미널에서 키를 숨김 입력받으며 의도적으로 `--key` 인자는 제공하지 않습니다. `delete`는 확인을 요청하고, `--yes`로 비대화형 삭제를 승인할 수 있습니다. 별도 설치는 `--config-dir /절대/경로`, 한국어 안내는 `--lang ko`를 추가합니다.

기존 설치에서 `setup`을 다시 실행하면 선택한 계정을 키체인 방식으로 이전합니다. `keychain migrate`는 브라우저 설정을 바꾸지 않고 기존 키 저장 방식만 이전합니다. `setup --env-file /절대/경로/key.env`는 해당 파일에서 키를 읽어 키체인으로 가져오며, macOS 설정에 환경 파일 참조를 남기지 않습니다. 두 API 키 환경변수의 값이 다르면 임의로 선택하지 않고 중단합니다.

업데이트 후 Aside의 확장 전용 MCP 연결을 재시작하세요. 설치된 `serve --extension` 실행기는 정책을 확인할 때마다 현재 키체인 값을 읽습니다. 일반 독립 실행 `serve`·`choose`와 데모 대시보드는 기존 환경변수 방식을 유지하며 특정 설치 계정에 자동 연결하지 않습니다.

## 저장되는 정보

서비스 이름은 `com.aside_jev.api-key`이고, 계정 식별자는 설치 폴더와 선택한 프로필 경로를 조합한 SHA-256 값입니다. 설정 JSON에는 이 참조와 `credential_store: "keychain"`, `env_file: null`만 기록합니다.

키는 Security.framework에 프로세스 내부 데이터로 전달하며 셸 명령 인자에 넣지 않습니다. 확장 팝업에 반환하거나 새로운 설정 백업에 기록하지 않습니다. 다만 API를 호출하려면 MCP 프로세스의 메모리와 환경변수에 일시적으로 존재해야 합니다. 키체인 저장 기능이며 Secure Enclave 저장이나 이미 침해된 로그인 세션으로부터의 완전한 보호를 뜻하지 않습니다. 동기화는 사용하지 않습니다.

상태 확인은 키 원문이 아니라 항목의 메타데이터를 요청합니다. 따라서 `configured`는 항목 존재를 뜻하며 실제 API 인증 성공이나 키체인 잠금 해제를 보장하지 않습니다. 실행 중 키체인이 잠기거나 접근이 거부되면 이전 환경변수나 평문 파일로 우회하지 않고 중단합니다. 키체인을 잠금 해제한 뒤 재시도하세요. 설치와 명시적인 키 변경에는 macOS 접근 승인 창이 표시될 수 있습니다.

## 기존 평문 사본

이전 과정은 키체인에 기록한 키를 다시 읽어 일치 여부를 확인합니다. 키 저장에 실패하면 설정 파일 변경을 원복하고 이전 키체인 항목 복구를 시도합니다.

**이전 성공을 확인한 뒤**, 옛 설치기가 관리하던 `<config-dir>/api.env`가 변경되지 않았을 때만 자동 삭제합니다. 외부 원본 파일이나 과거 백업 전체를 자동 삭제하지 않습니다. 관리 파일이 바뀌었거나 삭제할 수 없으면 정리 오류를 알립니다. 남은 원본·백업을 직접 점검하고 이미 노출된 키는 필요에 따라 폐기·교체하세요. 파일 삭제는 안전한 완전 삭제를 보장하지 않습니다.

삭제 명령은 해당 설치의 정확한 서비스·계정 항목만 지우며 브라우저 설정은 유지합니다. 다음 정책 검사부터 이전 환경변수 값을 버리고 키가 없으면 중단합니다. 이미 전송한 API 요청을 취소하거나 제공자 측 API 키를 폐기하는 기능은 아닙니다.

## 검증 범위

`tests/test_keychain.py`는 메모리 저장소로 기본 설치, 이전, 실패 복구, 삭제, 오래된 환경변수 무시와 평문 우회 방지를 검사합니다. 기존 설치기 단위 테스트에도 이 저장소를 명시적으로 적용해 사용자 키체인을 변경하지 않습니다.

`tests/test_keychain_native.py`는 macOS에서 임시 키체인과 가짜 키를 사용해 실제 Security.framework의 저장·조회·수정, 프로세스 간 조회, 잠금 상태 오류, 계정 격리와 삭제를 별도로 검사합니다. 기본 키체인을 변경하지 않습니다. 실제 Jev API나 사용자 Aside 계정은 사용하지 않습니다.
