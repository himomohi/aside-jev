# 다국어 지원

대시보드 기본 언어는 영어(`en`)이며, 확장은 접속 IP로 영어·한국어를 자동 선택합니다. 화면 언어를 바꿔도 사용자가 입력한 목표·후보·관찰·실행 payload는 번역하지 않습니다.

| 화면·산출물 | 기본 | 한국어 선택 | 문구 위치 |
| --- | --- | --- | --- |
| 대시보드 | 첫 방문 영어 | 헤더 언어 메뉴, 로컬 저장 | `src/aside_jev/static/i18n.mjs` |
| 확장 팝업 | 저장된 선택이 없으면 IP 자동 | 팝업 언어 메뉴, 로컬 저장 | `extension/i18n.mjs` |
| 확장 관리화면 메타데이터 | 영어 fallback | 브라우저 언어 적용 | `extension/_locales/{en,ko}/messages.json` |
| CLI 도움말·doctor | 영어 | `aside-jev --lang ko doctor` 또는 `aside-jev doctor --lang ko` | `src/aside_jev/cli_i18n.py` |
| 저장소 README | `README.md` | 상단 한국어 링크 | `README.ko.md`, `README.i18n.json` |
| 영상·GIF·포스터 | 접미사 없는 파일은 영어 | `.ko` 파일, `--locale ko` | `video/src/locales/{en,ko}.json` |
| 부속 문서 | 기본 파일은 영어 | `.ko.md` 번역본 | Markdown 문서 쌍 |

## 화면 동작

- 첫 대시보드는 영어이며 확장은 아래 IP 자동 언어 규칙을 따릅니다.
- 언어 선택은 각 화면에만 저장되며 OS·브라우저·Aside 계정 언어를 바꾸지 않습니다.
- 라벨·접근성 이름·placeholder·상태·기본 예제를 번역하되 사용자 수정 입력은 보존합니다.
- 알 수 없는 저장 언어는 대시보드에서 영어, 확장에서 자동 모드로 돌아갑니다. 저장소 사용 불가가 UI 동작을 막지 않아야 합니다.
- 확장 관리화면은 Chrome의 언어 선택을 따르므로 팝업의 명시적 선택과 다를 수 있습니다.
- 제품명·단위·후보 ID·JSON 키·오류 코드·API payload는 그대로 유지합니다.

백엔드·provider 진단과 생성하는 에이전트 지침은 원래 언어를 유지합니다. UI는 알려진 오류 코드를 번역하고 원문 진단은 별도 표시합니다. CLI는 도움말·doctor·자체 검증 문구를 번역하며 프로토콜 진단을 번역 API 계약으로 바꾸지 않습니다. 외부 파서·시스템 문구도 원래 언어일 수 있습니다.

대시보드는 Python 패키지에 포함되고 압축 해제된 확장은 독립 폴더로 배포되므로 UI 사전을 두 위치에 둡니다. 사전 동일성 검사로 두 복사본의 번역이 갈라지는 것을 방지합니다.

## README와 영상

GitHub Markdown에는 실행 중 언어 선택기가 없으므로 문서 상단에 번역본 링크를 제공합니다. [`README.i18n.json`](../README.i18n.json)은 언어별 README·영상·GIF·정지 화면·제품 화면을 연결합니다.

영상은 같은 composition·측정 JSON·시간 배율에 언어 사전만 교체합니다. [재현 방법](../video/README.ko.md)을 참고하세요. 두 언어 모두 localhost SDK 전송 실험이며 실제 모델 추론 비교가 아니라는 경계를 유지합니다.

## 번역 갱신

1. 영어 원문과 한국어 키를 함께 갱신하고 placeholder를 동일하게 유지합니다.
2. 사실·명령·제약이 바뀌면 두 문서를 함께 수정합니다.
3. 영상 문구 수정 후 두 언어를 렌더링하고, 제품 스크린샷은 실제 UI에서 갱신합니다.
4. 사전·언어 선택·문서 링크·산출물을 확인합니다.

```bash
uv run pytest -q
node --test tests/test_*i18n.mjs tests/test_extension_controller.mjs
uv run python scripts/check_i18n.py
cd video
bun run check
bun run render --locale all
bun run gif --locale all
```

번역 변경은 사용자 입력·모델 판단·계정 설정을 바꾸는 승인이 아닙니다.

간편 설치(`setup`)도 영어가 기본이며 `--lang ko`로 한국어 안내를 선택합니다. 초기 다운로드·런타임 준비 문구는 영어입니다.

## 확장 IP 자동 언어

확장 팝업과 키 입력 창은 수동 선택이 없으면 자동(IP)을 사용합니다. 한국(KR)은 한국어, 그 외는 영어입니다. 화면을 열 때 https://api.country.is/ 에 쿠키·자격 증명·리퍼러 없이 조회하며 국가만 사용하고 IP 응답은 저장하지 않습니다. 2.5초 내 조회에 실패하면 브라우저 언어를 사용합니다. 수동 영어·한국어 선택은 자동 감지보다 우선합니다. 툴팁과 접근성 이름도 같은 i18n 사전을 사용합니다. 툴바 제목은 팝업을 열 때 갱신되며 최초로 열기 전에는 Chromium의 manifest 언어를 따릅니다. 상주 worker나 새 권한은 추가하지 않습니다.
